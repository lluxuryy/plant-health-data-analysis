# Plant Health Data Analysis

A Python application for analyzing and visualizing plant health data using statistical analysis and Matplotlib. Developed for CS 3510: Computing for the Sciences at California State University, Stanislaus.

## Features

- Calculate descriptive statistics for plant attributes
- Compare attribute averages by plant health status
- Graph plant attributes over time
- Create correlation scatter plots with best-fit lines
- Calculate Pearson correlation coefficients

## Technologies

- Python
- Matplotlib
- Object-Oriented Programming
- CSV Data Processing

## How to Run

This project requires **Python 3** and **Matplotlib**.

Install Matplotlib:

```bash
pip install matplotlib
```

Then run:

```bash
python main.py
```

Generated graphs are saved as `plot.png`.
